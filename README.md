
# Ghost Markdown

[![Version](https://img.shields.io/github/package-json/v/MickyBalladelli/Markdown?style=flat-square&logo=visualstudiocode&logoColor=white)](https://github.com/MickyBalladelli/Markdown)
[![VS Code](https://img.shields.io/badge/VS%20Code-%E2%89%A51.137.0-007ACC?style=flat-square&logo=visualstudiocode&logoColor=white)](https://code.visualstudio.com/)

Ghost Markdown opens a `.md` or `.markdown` file in a VS Code panel beside a live rendered preview. You have three ways to use it:

## Three Ways to Use Ghost Markdown

1. **Edit in Ghost Markdown:** Type or paste Markdown in the left pane. Your changes are applied to the open VS Code document and appear in the preview as you type. The source field is plain text; it has no syntax highlighting or Markdown-specific editing tools.
2. **Edit in VS Code:** Keep using the regular VS Code editor. Ghost Markdown mirrors document changes in its source pane and refreshes the preview. Saving, undo, and redo are handled by VS Code as usual.
3. **Read the preview:** Use the right pane to read the rendered document while you edit in either source pane. The preview is read-only. In a narrow panel, the preview and source stack vertically.

## Use Ghost Markdown

1. Open a Markdown file in VS Code.
2. Choose **Open Markdown with Ghost Markdown** from the Command Palette.
3. Choose where to edit: Ghost Markdown's source pane or VS Code's editor. Read the rendered result in the preview.

## Supported Markdown

The preview renders:

- Headings and paragraphs
- Bold, italic, and strikethrough text
- Links and automatic URL linking
- Ordered and unordered lists
- Blockquotes
- Inline code and fenced code blocks
- Tables
- Line breaks within paragraphs
- Plain URLs as clickable links

Raw HTML is shown as text. Fenced code blocks are rendered without syntax highlighting.
